# Desk v0.11.0

Packs and graphs now share a **Decisions** browser. Build a graph from reusable packs in the composition editor, or ask the main chat to propose and rehearse one. Saving an assistant proposal still requires your explicit review and confirmation.

## What changes

- Browse all decisions, filter packs or graphs, search and organize them in folders, and preview a decision before opening it. Select packs to start a composition.
- Edit graph steps and their connections with the same controls and theme as the rest of Desk. Reuse a pack, map upstream outcomes or evidence availability, choose the result node, and undo or redo changes. Source JSON remains available.
- Ask the main chat to list or read decisions, obtain graph authoring guidance, validate and explain proposals, retain a graph draft, or rehearse a saved graph. Tool steps open their arguments and results in the details pane. The assistant cannot write a project graph directly.
- Rehearsal results identify the graph, configuration and per-node pack bytes evaluated by Runtime v0.29.0. Desk compares all bindings with current reads and reports changed or incomplete revisions instead of attaching old results to a new diagram. Matching bytes do not establish an atomic snapshot, correct policy or facts, review status, or authorization.
- Graph and decision-browser messages are translated in all 11 non-English catalogues.

## Data and compatibility

Graph edges pass data between steps: every node runs. They do not conditionally skip steps. Graph composition remains experimental; this release adds no graph conformance claim, nested graph execution, or scheduled graph Jobs. Runtime's conformance statement remains in its `CONFORMANCE.md`.

Standalone rehearsal inputs and results last until you leave the page and create no decision audit record. Chat-requested rehearsals and graph drafts are retained with the conversation; the selected model provider receives the chat's prompts and tool answers. Drafts remain separate from saved project files until you review and confirm a write.

Folders containing graphs use `jpack-folders.json` version 2. Older Desk versions cannot read this newer folder format; keep a project backup before downgrading. Existing pack and graph routes remain supported. Saving an edited graph in a reviewed project still requires **Review and lock** before deciding runs can use it.

The bundle pins Runtime v0.29.0, Runner v0.7.0 and Gateway v0.10.1. Companion executables are taken unchanged from their published, attested archives. Demo is excluded.
