# Desk v0.12.0

Packs and graphs now share a consistent workspace, with contextual chat and dedicated Brief, History and Usage tabs. The Library replaces the Decisions browser and makes folders, filters and selection actions easier to use.

## What changes

- **Library:** aligned shared menus, a single search and filter toolbar, folder dialogs, selection for drafts and saved items, and pagination. Pack and graph icons identify item types; draft status appears in the version column.
- **Pack and graph workspaces:** the same Overview, Logic, Sources, Tests, Review, Brief, History and Usage structure, with overflow navigation on smaller screens. Overview focuses on purpose and outcomes; detailed information stays in its own tab. Logic retains its diagram and list views.
- **Contextual chat:** the conversation stays attached to its pack or graph across tabs. Shared pane headers, session titles, history controls and width controls reduce duplicated actions. Tables and code scroll within messages and can expand into a wider dialog.
- **Draft checks:** Desk verifies saved check bindings and source proofs after reload before using them for readiness. Changed inputs, sources or Runtime context are reported as outdated; opening a draft does not silently call a model or rerun its tests.
- **Brief:** explicitly generate and retain a summary of a saved pack or graph, its saved tests and open questions. Merely opening the tab does not call a model. A brief does not approve or finalize anything.
- **History:** inspect available draft revisions, saved checks, brief revisions and matching Runtime decision records. Event summaries use plain language. Content fingerprints and original saved data remain available under Technical details, with export of the original operational record text.
- **Usage:** inspect confirmed references from graphs and frozen job releases, and follow links to Jobs. Incomplete inventories are identified rather than presented as complete.
- **Translations:** complete UI catalogs for all 11 supported translated languages, including the new Library, Brief, History, Usage and verification messages. Overview and Brief labels are distinct, and Usage describes where a definition is used.
- **Connections and feedback:** more consistent AI connection and model selection, reconnect handling, compact connection status, accessible shared notices and aligned menus.

## Data and compatibility

History displays available records; it is not a complete authoring or action audit journal. Viewing a record does not verify its signature, timestamps, checkpoints or cited receipts. Decision safeguards retains the existing project verification tools. Some graph draft and test observations exist only in the current browser session and are labelled accordingly.

Graph composition remains experimental. Every node runs; connections pass outcomes or evidence availability and do not conditionally skip steps. This release adds no nested graph execution or scheduled graph Jobs. Usage for a job describes its frozen release, not subsequent edits to a pack.

An AI-generated brief sends the selected definition and saved supporting context to the chosen model provider only when generation is requested. Saved briefs and test observations do not establish current readiness or operational authorization.

The bundle keeps Runtime v0.29.0, Runner v0.7.0 and Gateway v0.10.1. Published, attested companion executables remain unchanged. Existing projects require no automatic configuration, signing-key or Jobs-store migration. The folder-format compatibility caveat introduced in v0.11.0 still applies when downgrading. Demo is excluded.
