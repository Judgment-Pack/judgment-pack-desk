# Desk v0.13.2

Desk updates `github.com/go-jose/go-jose/v4` from 4.1.5 to 4.1.6 to address [GHSA-mgcc-cww5-fp2q](https://github.com/go-jose/go-jose/security/advisories/GHSA-mgcc-cww5-fp2q), a denial-of-service risk from excessive CPU use while parsing crafted RSA private JWKs. The updated parser applies a default 4096-bit maximum RSA modulus size.

RSA JWKs above 4096 bits are rejected. If a JWKS contains supported keys and any one of them exceeds this limit, parsing rejects the supported key set, including otherwise valid keys in that set. Operators whose identity provider publishes RSA keys larger than 4096 bits should coordinate key rotation with the provider and confirm that its JWKS contains keys within the supported limit before upgrading. Desk does not provide an override for this cap.
