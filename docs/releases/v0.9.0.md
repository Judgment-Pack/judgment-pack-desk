# Desk v0.9.0

Graphs in Desk, held to a record. A project's declared graphs now show the runtime's plan and findings beside the inventory, the Tests view is held to what each label and member establishes, and every string added since v0.7.0 is translated in all eleven catalogues. The pinned Gateway moves to v0.10.1, which follows no redirect to another origin when it snapshots a public web source. Runtime 0.27.1 and Runner 0.6.0 are unchanged.

**Updating from v0.8.0 needs no backup step:** nothing here changes a desk's `jpack.json`, a Jobs store, a lock or a signing key.

## What changes for you

- **Graphs: plan and findings** (Project → Graphs). Beside the inventory of a project's declared graphs, Desk shows the runtime's findings for them (`jpack experimental graph validate`) and, for each graph, its evaluation plan (`explain`), with the runtime's sentences verbatim and its labels as it prints them: every graph payload is `experimental`, which names the stability of the surface, not a claim about what a graph establishes. No absolute path reaches the page.
- **Graphs: the Tests view, held to the record.** On the Tests view (the matrix rows, run only when you ask), every label the runtime prints — `kind`, `experimental`, `conformanceClaimReference` — is shown beside its `label`, each as what it is; the suite's and each graph's summary are the runtime's own members in its own order (passed, mismatched, total), with no sentence of Desk's turning them into a verdict; every row's sentence and detail is marked as the runtime's English and redacted like the rest.
- **Every string in every language.** The 275 strings added since v0.7.0 (the decision record's new sentences, AI connections, search and files, Admin by task, document processing) are translated in de, es, fr, it, ja, ko, pt-BR, pt-PT, yue-Hant, zh-Hans and zh-Hant, matched to each catalogue's existing terms.
- **Gateway v0.10.1.** A public web source whose server redirects to another origin is refused rather than followed; everything else is as in v0.10.0.

## What a graph result establishes, and what it does not

ADR-0011, accepted with this release's first delivered row: a graph's disposition in Desk is the runtime's experimental answer over the project's packs, shown as given. No JPS version defines a graph, so Desk makes no conformance claim for one; nothing about a graph is recorded in the decision record's trail (a graph evaluation in Desk is a rehearsal, and the trail is silent about rehearsals, as runtime ADR-0048 says); Jobs executes no graph. The runtime's words for `experimental` and for the conformance locator are shown as the runtime words them.

## Graphs: plan, findings and labels (#341, ADR-0011 row 1)

- `GET /api/graphs/findings` runs `graph validate`; `GET /api/graphs/plan?id=` runs `graph list` to resolve the id to its declared path, then `explain` on the cleaned path, both through Desk's runtime runner with its 20 s and 64 KiB bounds; an answer that is not the command's own, or none at all, is a fixed error, never a partial payload.
- The id is compared only with ids from a fresh listing and never reaches the runtime; a listed path is cleaned before any command and refused if it still climbs out of the project (a symlinked folder followed by `..` is tested against the published runtime); containment is checked before any runtime detail is shown.
- Every path-bearing member (`path`, `rowsPath`, `graphPath`, `configPath`, `steps[].path`) and every sentence naming a path is shown relative to the project or redacted, including the error path; the redaction now holds for a folder name with a space, a tab or U+2028 (the previous rule stopped at the first space).
- `kind` and `experimental` are passed through exactly as the runtime printed them; the findings' summary is the runtime's members, with no sentence of Desk's.

## Graphs: the Tests view held to the record (#343, ADR-0011 row 2)

- `kind`, `experimental` and `conformanceClaimReference` are shown through the same component as the inventory, only when the payload carries them and with the value the runtime printed (measured against 0.27.1's real matrix payload over MCP: `experimental: true`, `conformanceClaimReference: "CONFORMANCE.md"`); a missing member produces no label.
- The summary lists the runtime's members as printed; the row line names what decides a row's status (the dispositions, the coverage and every hand-off target assertion the row made); the closing note says what a run shows and, in ADR-0011 §9's words, what it does not establish (a JPS result, a record in the trail, an authorization); a binding notice says which bytes both answers are about and no more.
- A quoted absolute path in any sentence of the payload is redacted whole, holding for a folder name with a space, a tab or U+2028 (the runtime prints `configPath` relative, so the redaction keys on the quoted path itself); probe detail is marked as the runtime's English.
- Row sides still show a Desk summary compared by Desk, which §4 does not allow; filed as #344 for the next row.
